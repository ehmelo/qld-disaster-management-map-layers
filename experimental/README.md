# Experimental variants

Test files for the Azure Maps rendering fault on Cook Shire (phantom triangles between enclaves and the coast). Only Cook Shire differs from the published council layer; do not use these in production. `keyhole`: each enclave joined to the outer ring by a 60 m channel. `split`: Cook cut into east-west bands through the enclaves. Both remove interior rings from Cook Shire. Generated by build-experimental-cook-variants.py.
